Product Requirements Document (PRD)
Reading and Writing Numbers — Grade 1 Math
Intellia SG | Singapore Primary Mathematics Curriculum

1. Executive Summary
This document defines product requirements for the "Reading and Writing Numbers" interactive lesson module, delivered as part of Intellia SG's Grade 1 Math program (Lesson 1.2). The module targets Singapore Primary 1 students aged 6–7 and covers numbers 0–100 using a gamified, simulation-based learning model aligned with the Singapore Mathematics Framework (MOE).
The product is a standalone web page hosted at https://intelliasg.com/courses/grade-1-math/lessons/reading-and-writing-numbers/ built using React and designed to match the visual and UX style established at https://number-counting-gamma.vercel.app/.

2. Product Vision & Goals
Vision
To make number literacy fun, memorable, and effective for 6–7 year old Singapore students by combining animated simulations, scaffolded learning, and adaptive gamified practice.

4. Curriculum Alignment (Singapore MOE)
Topic: Reading and Writing Numbers (Primary 1, Unit 1.2)
Learning Objectives (from Targeting Mathematics Primary 1A & 1B):

Count, read and write numbers 0 to 10 (Phase 1)
Count, read and write numbers 0 to 20 (Phase 2)
Count, read and write numbers 0 to 40 (Phase 3)
Count, read and write numbers 0 to 100 (Phase 4)
Recognise number words (zero, one, two... ten, twenty... hundred)
Write numbers in numerals and in words
Match numerals to quantities using visual representations (ten-frames, number lines, base-10 blocks)

Singapore Syllabus Concepts Covered:

Number notation: numerals, number words
Place value representation (tens and ones) for numbers up to 100
Ordinal connection (sequence awareness)
Visual-concrete-pictorial-abstract (CPA) progression

6. Gamification Design
6.1 Reward System

Stars (⭐): Earned per correct answer (max 3 stars per question set)
XP Points: 10 XP per correct, 5 XP per retry-correct
Badges: Unlockable milestones

🏅 "Number Newbie" — Complete Learning Phase
🥈 "Practice Pro" — Complete 10 practice questions
🥇 "Number Master" — Score 80%+ on Challenge
💎 "Perfect Speller" — 100% on number words


Streak Counter: Consecutive correct answers shown with fire emoji 🔥
Progress Bar: Visual journey map (Learning → Practice → Challenge)

6.2 Feedback Mechanics

✅ Correct: Celebratory animation + sound + encouraging message ("Amazing! You got it! 🎉")
❌ Incorrect: Gentle retry message + hint shown ("Let's try again! Hint: Count the blocks 🧱")
Max 2 hints per question, then answer revealed with explanation
No negative scoring — encouragement-first approach

6.3 Character / Mascot

Friendly monkey mascot (aligned with Casco Publications Targeting Mathematics theme)
Mascot reacts: happy when correct, thinking when question appears, cheering at milestone


7. UX & Design Requirements
7.1 Visual Design

Theme: Bright, tropical, child-friendly (matching number-counting-gamma.vercel.app)
Colours: Sky blue primary, golden yellow accent, coral red for alerts, white backgrounds
Typography: Rounded, readable fonts (e.g. Nunito, Fredoka One)
Icons & Illustrations: Cartoon-style, consistent art style
Animations: Smooth, delightful, purposeful (not distracting)

7.2 Accessibility

Large click targets (minimum 44x44px)
High contrast text (WCAG AA minimum)
Audio narration for all questions (text-to-speech or recorded)
Keyboard navigable
No time pressure (optional timer mode for advanced users)

7.3 Responsive Design

Optimised for tablets (iPad primary device for classroom)
Works on desktop browsers
Mobile-friendly layout


8. Content Requirements
8.1 Number Ranges

Phase 1: 0–10 (foundation)
Phase 2: 11–20 (teen numbers — explicitly taught as special case in Singapore syllabus)
Phase 3: 21–40 (two-digit with pattern recognition)
Phase 4: 41–100 (full range with tens/ones structure)

8.2 Question Bank (100 Questions)

Minimum 10 questions per question type
All questions randomised per session (no two sessions show same order)
Questions drawn from real Singapore Primary 1 textbook examples (Targeting Mathematics, My Pals Are Here)
Word problems use Singapore-context names (Megan, Wei Ming, Priya, Raju, Ahmad)

8.3 Audio

Number word pronunciation for all 1–100
Question read-aloud support
Celebration sound effects
Background ambient music (optional, toggleable)


9. Technical Platform Requirements

Framework: React (JSX) — single file deployable
Hosting: Integrated into WordPress page at intelliasg.com via iframe or embedded
Browser Support: Chrome, Safari, Edge (latest 2 versions)
No login required — works as guest learner
Progress: Saved to localStorage (session persistence)
Analytics: Track question attempts, scores, completion rates (future phase)
