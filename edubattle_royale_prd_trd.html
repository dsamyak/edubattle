1. Product Overview

PRD § 1

EduBattle Royale is a web-based competitive learning platform where students engage in real-time academic duels. Unlike traditional quiz apps, it fuses quiz knowledge with strategic decision-making — students must not only know the answer, but choose when and how to play it.

The platform targets students aged 14–22 across school and college environments, gamifying revision sessions and making peer-to-peer learning inherently engaging.

🔥

2. Problem Statement

PRD § 2

Current Pain

Existing EdTech tools are passive and solitary. Students use flashcard or quiz apps alone, with no social accountability or competitive pressure to drive deeper retention.

Opportunity

Games like Battlegrounds and Clash Royale have proven that real-time competition drives engagement for hours. EduBattle brings the same psychology to academics.

5. Core Features (MVP)

PRD § 5

MODE 1 — 1V1 QUIZ DUEL

  • Real-time matchmaking with ELO rating system
  • Timed question rounds (10, 20, 30 second options)
  • Answer confidence betting — wager points on each answer
  • Live HP-style health bars depleted by wrong answers or slow responses
  • Post-match stat review: accuracy, speed percentile, topic weaknesses

MODE 2 — TEAM STRATEGY LEARNING

  • 2v2 or 3v3 team battles with subject specialisations per member
  • Each player assigned a "role": Attacker, Defender, Support
  • Team can vote to use power-ups (Skip, Hint Reveal, Double Points)
  • Collaborative answer consensus round for bonus strategic questions

MODE 3 — SPEED CHALLENGE

  • Solo blitz mode: 50 questions, fastest correct time wins
  • Global leaderboard updated in real-time
  • Daily challenge with exclusive rewards for top 10
💡

6. Unique Twist — Strategy Layer

PRD § 6

Power Cards

Students earn strategic cards via winning streaks: "Shield" blocks damage from one wrong answer, "Double Down" bets 2× points on a question, "Blackout" hides opponent's timer.

Confidence Wagering

Before each answer, players rate their confidence (Low / Med / High). High-confidence correct answers score 3×; wrong answers penalise accordingly. Metacognition as gameplay.

Subject Deck Building

Students curate their own question decks from a library. Entering a match with a focused deck gives a "Home Turf" bonus — rewarding preparation and specialization.

Boss Raids

Weekly 10-player cooperative battles against an AI "Knowledge Boss" — a sequence of increasingly hard questions requiring team coordination to defeat.

4. WebSocket Event Protocol

TRD § 4

CLIENT → SERVER

  • battle:join — join matchmaking queue
  • battle:answer — submit answer + confidence
  • battle:card_play — activate power card
  • team:vote — team power-up vote
  • battle:forfeit — surrender match

SERVER → CLIENT

  • battle:matched — opponent found, match start
  • battle:question — push next question + timer
  • battle:result — round outcome + HP update
  • battle:ended — match over, final stats
  • battle:sync — state sync on reconnect

7. Security & Anti-Cheat

TRD § 7
  • All answers validated server-side — client never receives correct answer before submission
  • JWT access tokens (15 min TTL) + HTTP-only refresh tokens (7 days)
  • Socket events authenticated via JWT on every connection handshake
  • Server-controlled question timer — client timer is display only, server rejects late submissions
  • Rate limiting on answer events: max 1 answer per question per socket per round
  • Input sanitisation via Zod on all REST endpoints and socket payloads
