1. Technology Stack
TRD § 1
Layer	Technology	Rationale
Frontend	React 18 + Vite	Component reuse, fast HMR, ideal for real-time UI state
Styling	Tailwind CSS + CSS Modules	Utility-first for speed, modules for scoped arena components
State Management	Zustand	Lightweight, no boilerplate, works well with WebSocket events
Real-time	Socket.io (WebSocket)	Reliable bidirectional events, auto-reconnect, room support
Backend	Node.js + Express	Non-blocking I/O — critical for concurrent match sessions
Database	PostgreSQL + Redis	Postgres for persistent data; Redis for match state & pub/sub
Auth	JWT + bcrypt	Stateless auth, short-lived tokens, refresh token rotation
ORM	Prisma	Type-safe DB queries, migrations, easy schema iteration
Hosting	Vercel (FE) + Railway (BE)	Zero-config deploys, free tiers suitable for internship demo

— submit answer + confidence

— activate power card

— team power-up vote
battle:forfeit
— surrender match
SERVER → CLIENT

battle:matched
— opponent found, match start
battle:question
— push next question + timer
battle:result
— round outcome + HP update
battle:ended
— match over, final stats

— state sync on reconnect

7. Security & Anti-Cheat
TRD § 7
All answers validated server-side — client never receives correct answer before submission
JWT access tokens (15 min TTL) + HTTP-only refresh tokens (7 days)
Socket events authenticated via JWT on every connection handshake
Server-controlled question timer — client timer is display only, server rejects late submissions
Rate limiting on answer events: max 1 answer per question per socket per round
Input sanitisation via Zod on all REST endpoints and socket payloads
